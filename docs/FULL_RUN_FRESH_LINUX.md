# Fresh-Linux full manuscript run

This guide describes the publication-facing full SEN workflow from a new Linux
machine. It distinguishes three things that must not be conflated:

1. the **3,434-genome starting metadata/SRA cohort**;
2. reconstructed QC/typing results generated by the current pinned workflow;
3. the **frozen historical final manuscript cohort of 3,306 study SRRs**
   recorded in `metadata/final_clade_metadata.tsv`.

The repository intentionally does not mutate `metadata/SEN_Genomes.csv`.

## 1. Compute and storage planning

A full 3,434-genome run is a workstation/HPC job.

Recommended practical starting point:

- Linux x86_64
- 32+ CPU threads; 64+ is preferable
- >=128 GB RAM for comfortable phylogenomics/pangenome work
- several hundred GB of free storage; 1 TB or more is recommended if raw reads,
  trimmed reads, assemblies, indexes, and intermediate files are retained
- fast local scratch for SRA conversion, Kraken2, assembly, and Gubbins

The pinned Kraken2 Standard database alone is approximately 103 GB extracted.

## 2. Install Linux prerequisites and Conda

Ubuntu/Debian:

```bash
sudo apt update
sudo apt install -y git curl wget ca-certificates bzip2 build-essential
```

Install Miniforge:

```bash
cd ~
curl -L -o Miniforge3.sh \
  https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-Linux-x86_64.sh
bash Miniforge3.sh -b -p "$HOME/miniforge3"
source "$HOME/miniforge3/etc/profile.d/conda.sh"
conda init bash
```

## 3. Clone the manuscript repository

```bash
git clone https://github.com/ShahShringiLab/SEN_genomics_pipeline.git
cd SEN_genomics_pipeline
```

For a published analysis, checkout the manuscript release tag/commit.

## 4. Static publication audit

Before downloading data:

```bash
bash scripts/publication_audit.sh
```

The expected ending is:

```text
STATIC PUBLICATION AUDIT: PASS
```

This validates code contracts and frozen metadata/database declarations; it is
not a substitute for the full biological rerun.

## 5. Create all declared environments

```bash
bash scripts/setup_all_envs.sh
```

This creates the environments declared under `environments/` and leaves
already-existing environments untouched.

## 6. Set the project root

The simplest reproducible layout is to let the clone itself be the project
root:

```bash
export SEN_ROOT="$PWD"
export TMPDIR="$SEN_ROOT/tmp"
mkdir -p "$TMPDIR"
```

Machine-specific overrides can instead be placed in an untracked
`config/paths.env`, using `config/paths.example.env` as a template.

## 17. Retrospective QC audit

The non-destructive QC audit is:

```bash
conda run --no-capture-output -n sen_stats \
  env SEN_ROOT="$SEN_ROOT" SEN_METADATA_FILE="$SEN_ROOT/metadata/SEN_Genomes.csv" \
  python workflow/02_qc/08_qc_filter.py
```

Do **not** use `workflow/02_qc/05_two_step_filter.sh` for the publication
reproduction. That historical script moves files and rewrites the metadata
file. It is retained only as provenance until removed/deprecated.

The retrospective audit reconstructs the historical coverage/SISTR/SeqSero2
logic. Historical final inclusion additionally involved retained coverage
exceptions and IQ-TREE screening, so this audit must not silently redefine the
published final cohort.

## 32. Clade-level descriptive/statistical analyses

```bash
for script in \
  14b_cladesummary.py \
  15_amr_byclade.py \
  16_plasmid_byclade.py \
  17_resfinder_byclade.py \
  18_vfdb_byclade.py
do
  conda run --no-capture-output -n sen_stats \
    env SEN_ROOT="$SEN_ROOT" \
    python "analysis/clades/$script"
done
```

The corrected sparse-count contract uses 5,000 Monte Carlo resamples with RNG
seed 12345 when expected cells are <5, BH FDR across loci, and Holm-adjusted
pairwise Fisher tests within significant loci.

## 34. EggNOG / COG functional annotation

The manuscript used EggNOG-mapper v5.0.2 through Galaxy. This is an external
annotation step and is not silently replaced by a different local database.

The FASTA packages generated by the SNP/FGA scripts are submitted to the
specified EggNOG workflow. Preserve the returned tabular annotation files under
the expected `iqtree_final/FGA/` names before running:

```bash
conda run --no-capture-output -n sen_stats \
  env SEN_ROOT="$SEN_ROOT" \
  Rscript analysis/snps/FGA.R

conda run --no-capture-output -n sen_stats \
  env SEN_ROOT="$SEN_ROOT" \
  Rscript analysis/snps/FGA2.R
```

Do not claim a complete COG reproduction until the exact external EggNOG
version/database provenance is recorded.

Also inspect:

Before manuscript freeze, verify:

- SnpEff reference/database provenance;
- EggNOG/PHASTER/HMMER external-service provenance;
- unresolved historical MLST/Gubbins/AMRFinder software-version differences.

## 37. Re-running and resuming

Most expensive per-sample workflow stages are resume-safe and skip valid
existing outputs. Do not delete result directories simply to restart an
interrupted run.

The smoke suite has stronger signature-based checkpoints. The full workflow is
currently run stage-by-stage so that manuscript-scale outputs can be inspected
at each freeze gate.

## 38. Publication interpretation

A fresh run with current frozen reconstruction assets is a **reproducible
reconstruction** of the manuscript workflow. Where historical software/database
versions are not recoverable, the repository records that discrepancy rather
than silently rewriting the historical Methods.
