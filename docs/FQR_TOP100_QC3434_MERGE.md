# Part A: full-master FQR Top-100 plot and 3,434-genome QC metadata

## Full-master FQR Top-100 chart

The preserved original notebook is `provenance/SEN_Genomes2.Rmd`.
`scripts/prepare_original_part_a2.py` creates a working copy (without modifying
that archived source) and changes the `FQR_marker_counts_top100` horizontal
count-axis maximum from 22,000 to **25,000**. It patches
`scale_y_continuous(limits=c(0, 25000))` because the chart uses `coord_flip()`.
Bar data, labels, percentages, colors, plot dimensions, and saved filenames
are not otherwise changed. The 3,434-cohort chart in
`results/part_a/genotype_summary/` has its own automatically scaled axis;
the requested 25,000 maximum applies to the **33,831-master chart**.

The generated master chart files are written into the repo working directory
by the original notebook and/or extracted execution script:
`FQR_marker_counts_top100.png`, `.tif`, and `.pdf`.

## Full 3,434-genome metadata: validated QC merge

Authoritative immutable inputs:

- `data/part_a/selection/Finalupdated_SEN_Genomes1.csv`: 3,434 rows,
  69 original metadata columns.
- `data/part_a/selection/Selected_US-SEN_12192025_QCAUDIT_R1_qr_clade.csv`:
  3,434 rows of curated QR/FQR corrections, clades, QC/phylogeny inclusion,
  and per-sample `AUDIT` comments.
- `metadata/final_clade_metadata.tsv`: the canonical 3,306 final
  phylogenetic clade assignments, plus reference.

`python3 scripts/merge_qc_full_metadata.py` performs an exact
`Run + Isolate` merge, requires identity of all 3,434 unique pairs and
validates each clade against the final tree metadata.
Original QR and FQR calls remain in `QR_genotype_archived` and
`FQR_genotype_archived`; `QR_genotype` and `FQR_genotype` hold the
validated corrected calls. Adds QR status, per-genome marker count/list,
correction flag, clade, inclusion status, and the complete QC `AUDIT` note.

Expected QC totals:
- 3,434 genomes, 78 columns (all original 69 + nine audit columns)
- 3,306 included in the phylogeny; 128 excluded
- Three corrected QR/FQR genotype calls
- Two **retained** historical isolates with explicitly documented coverage
  exceptions; neither is erroneously rejected
- 2,288 corrected QR/FQR-marker-positive selected isolates

Generated outputs (not edits to the original metadata):
```
results/part_a/cohort/Finalupdated_SEN_Genomes1_QC_merged.csv
results/part_a/cohort/QC_merged_3434_validation.json
```

The derived marker summary, source profiles and diversity/composition analyses now read the QC-merged metadata directly, not the unaugmented reconstructed 3,434-genome file.\n\nThe merge runs automatically with `bash scripts/run_master_part_a2.sh`
or the full `bash scripts/run_part_a.sh`. The complete Part A runner
also runs `scripts/validate_part_a_outputs.py`, checking that the merged
metadata agree with the independently rebuilt cohort and final clades.

The merged CSV is generated by the run and is not currently a separately
versioned GitHub data file. The canonical source metadata and QC overlay
are both versioned, and the merge is reproducible from these inputs.
